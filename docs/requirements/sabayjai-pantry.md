## 1. ข้อมูลภาพรวม (Overview)

- **ชื่อระบบ/ฟีเจอร์:** SabayJai Pantry — ระบบสต็อกของกินในบ้าน (เดโมสาธิต)
- **เป้าหมายหลัก (ตามลำดับความสำคัญ):**
  1. รู้ว่าตอนนี้ **มีอะไร อยู่ตรงไหน และเหลือเท่าไร**
  2. รู้ว่า **ของอะไรใกล้หมดอายุเมื่อไหร่** เพื่อใช้ให้ทันก่อนทิ้ง
- **ผู้ใช้งาน (Users):** คนในบ้านที่ใช้ครัวร่วมกัน — ในเดโมนี้ใช้ในเบราว์เซอร์ของแต่ละเครื่อง ไม่มีบัญชีและไม่มีการแชร์ข้ามเครื่อง
- **ลักษณะของเดโม:** **Frontend Only** ไม่มี Backend ไม่มีระบบสมาชิก ข้อมูลเก็บใน localStorage ของเบราว์เซอร์

**บริบทโดยย่อ:** บ้านมีตู้เย็นและที่เก็บหลายจุด ของที่จัดเก็บมีทั้งของพร้อมกินและวัตถุดิบ ผู้ใช้เป็นผู้เลือกเองว่าจะบันทึกอะไร และเลือกหมวดหมู่ของเองได้

## 2. ขอบเขต (Scope)

### 2.1 สิ่งที่ระบบทำได้ (In Scope)

| # | ขอบเขต | รายละเอียด |
|:--:|---|---|
| 1 | บันทึกของเข้าจุดเก็บ | บังคับ: ชื่อ · จำนวน · หน่วย · จุดเก็บ — ไม่บังคับ: วันหมดอายุ · หมวดหมู่ · หมายเหตุ |
| 2 | ดูและค้นหารายการทั้งหมด | ดูทุกอย่างในที่เดียว · ค้นหาชื่อและข้อความในหมายเหตุ · กรองตามจุดเก็บและหมวดหมู่ |
| 3 | ปรับจำนวนเมื่อหยิบใช้ / ทำอาหาร / ทิ้ง | ปรับได้จากหน้ารายการ · ลดถึง 0 แล้วย้ายเข้า "ใช้หมดแล้ว" อัตโนมัติ พร้อม undo 5 วินาที |
| 4 | จัดหมวดหมู่ของได้เอง | ผู้ใช้เพิ่ม/แก้/ลบหมวดหมู่ได้ เริ่มจากค่าเริ่มต้น 4 หมวด: พร้อมกิน · วัตถุดิบ · เครื่องปรุง · ของใช้ในครัว |
| 5 | ดูข้อมูลตามตำแหน่งที่เก็บ | 5 จุดเริ่มต้น: ตู้เย็น · ช่องแช่แข็ง · ตู้กับข้าว · ชั้นวางของ · ตะกร้าผัก-ผลไม้ — เพิ่ม/แก้/ลบได้ |
| 6 | รู้ของใกล้หมดอายุ | เหลือ ≤ 3 วัน = ใกล้หมดอายุ (เหลือง) · เลยวัน = หมดอายุ (แดง) · มีมุมเฉพาะ + สรุปตอนเปิดแอป |
| 7 | มุม "ใช้หมดแล้ว" + ประวัติย้อนหลัง | ของที่ใช้หมดยังดูย้อนหลังได้ และนำกลับเข้ารายการได้ |
| 8 | รายการที่ต้องซื้อ | สมุดโน้ตอิสระ: พิมพ์เพิ่มเอง · ติ๊ก "ซื้อแล้ว" แล้วหายจากรายการ · ไม่ผูกกับรายการของ |
| 9 | รีเซ็ตข้อมูลตัวอย่าง | ปุ่มคืนค่าข้อมูลตัวอย่าง (seed) ให้กลับมาเริ่มสาธิตใหม่ได้ |

### 2.2 สิ่งที่ยังไม่ทำในตอนนี้ (Out of Scope)

- ระบบสั่งซื้อ / เชื่อมร้านค้าออนไลน์
- ระบบบัญชีครัวเรือน และคำนวณโภชนาการเชิงลึก
- การแชร์ข้อมูลออกนอกบ้านแบบสาธารณะ
- **ระบบบัญชี/สมาชิก/การซิงก์ข้ามเครื่อง** (ไม่มี Backend — ข้อมูลอยู่เฉพาะเบราว์เซอร์ของเครื่องนั้น)
- **การแจ้งเตือนนอกแอป** (LINE / push / Notification API)
- สแกนบาร์โค้ด · ถ่ายรูปภาชนะ · สั่งด้วยเสียง
- การเก็บรูปของ (localStorage มีพื้นที่จำกัด)
- Backend / ฐานข้อมูลบนคลาวด์ ทุกชนิด

### 2.3 ข้อจำกัดที่รู้ตัวของเดโม (Known Limitations)

1. **ข้อมูลไม่แชร์ข้ามเครื่อง** — เป้าหมาย "ทุกคนเห็นของตรงกัน" เป็นจริงได้เฉพาะในเครื่องเดียวในเดโมนี้
2. **ข้อมูลหายได้** เมื่อผู้ใช้ล้างข้อมูลเบราว์เซอร์หรือเปลี่ยนเครื่อง
3. **การเตือนแม่นเท่าที่คนกรอก** — วันหมดอายุเป็นช่องไม่บังคับ ของที่ไม่กรอกจะไม่เข้าเตือน
4. **รายการที่ต้องซื้อไม่ผูกกับรายการของ** (ตามข้อ 16 = c และ OQ-15) — ของที่หมดไม่ขึ้นเอง และติ๊ก "ซื้อแล้ว" แล้วของไม่กลับเข้ารายการของโดยอัตโนมัติ (จดเป็นงานอนาคต)

## 3. รายการความต้องการ (User Stories & Requirements)

> เกณฑ์ตรวจรับทุกข้อเป็น checklist ที่ติ๊กได้จริง ใช้เป็นหลักฐานการตรวจรับของมนุษย์

### US-001 · บันทึกของเข้าจุดเก็บ
- **ในฐานะ:** คนในบ้าน · **ฉันต้องการ:** เพิ่มของพร้อมบอกว่าอยู่จุดเก็บไหนและเหลือเท่าไร · **เพื่อที่จะ:** รู้ว่ามีของนี้อยู่
- **ที่มา:** ข้อ 5, 6, 7, 15
- **เกณฑ์การตรวจรับ:**
  - [ ] เพิ่มของ 1 ชิ้นได้ภายในไม่เกิน 3 ขั้นตอน
  - [ ] บังคับกรอก ชื่อ · จำนวน · หน่วย · จุดเก็บ — ไม่กรอกครบแล้วบันทึกไม่ได้
  - [ ] วันหมดอายุ · หมวดหมู่ · หมายเหตุ เป็นช่องไม่บังคับ
  - [ ] หน่วยเลือกจากรายการสำเร็จรูป (ชิ้น · กล่อง · ขวด · ถุง · แพ็ก · ฟอง · หัว · กรัม · กิโลกรัม · ลิตร · มล.) และพิมพ์หน่วยใหม่เองได้
  - [ ] พิมพ์ชื่อ 2–3 ตัวอักษรแล้วมีรายการของที่เคยบันทึกให้เลือกใช้ซ้ำได้
  - [ ] เพิ่มหมวดหมู่ใหม่ในหน้าเพิ่มของได้ทันที แล้วเลือกใช้หมวดนั้นได้โดยไม่ต้องออกจากหน้า

### US-002 · ดูและค้นหารายการของทั้งหมด (รวม US-006 กันซื้อซ้ำของฉบับร่าง)
- **ในฐานะ:** คนในบ้าน · **ฉันต้องการ:** เห็นภาพรวมทุกอย่างในบ้าน และเช็กได้ว่าของชิ้นนี้มีอยู่แล้วไหม · **เพื่อที่จะ:** ตัดสินใจว่าจะกินหรือซื้ออะไร โดยไม่ซื้อซ้ำ
- **ที่มา:** ข้อ 2, 6, 17
- **เกณฑ์การตรวจรับ:**
  - [ ] เปิดแอปแล้วเห็นรายการของทั้งหมดที่มีอยู่
  - [ ] การ์ดแต่ละรายการแสดง ชื่อ · จำนวน + หน่วย · จุดเก็บ · (ถ้ามี) วันหมดอายุและสถานะสี
  - [ ] กรองตามจุดเก็บได้ และกรองตามหมวดหมู่ได้ พร้อมกันได้
  - [ ] ค้นหาด้วยชื่อของเจอ
  - [ ] ค้นหาด้วยข้อความในหมายเหตุเจอ (ค้นคำว่า "ของยาย" แล้วเจอรายการนั้น)
  - [ ] ยังเห็นจำนวนคงเหลือและจุดเก็บของผลลัพธ์ที่ค้นเจอ

### US-003 · ปรับจำนวนเมื่อหยิบใช้
- **ในฐานะ:** คนในบ้าน · **ฉันต้องการ:** ลดหรือปรับจำนวนเมื่อหยิบใช้หรือทิ้ง · **เพื่อที่จะ:** ยอดคงเหลือตรงกับของจริง
- **ที่มา:** ข้อ 10
- **เกณฑ์การตรวจรับ:**
  - [ ] ปรับจำนวนได้จากหน้ารายการ โดยไม่ต้องเข้าหน้ารายละเอียด
  - [ ] จำนวนติดลบไม่ได้
  - [ ] ลดจำนวนถึง 0 แล้วย้ายเข้า "ใช้หมดแล้ว" อัตโนมัติ
  - [ ] หลังย้ายมีปุ่ม undo ให้กดย้อนกลับได้ภายใน 5 วินาที

### US-004 · ดูตามตำแหน่งที่เก็บ
- **ในฐานะ:** คนในบ้าน · **ฉันต้องการ:** ดูว่าจุดเก็บแต่ละจุดมีอะไรบ้าง · **เพื่อที่จะ:** หยิบของได้เร็วและจัดของเป็นระเบียบ
- **ที่มา:** ข้อ 7, 14
- **เกณฑ์การตรวจรับ:**
  - [ ] เลือกดูทีละจุดเก็บได้ และเห็นเฉพาะของในจุดนั้น
  - [ ] เพิ่ม · แก้ชื่อ · ลบ จุดเก็บได้
  - [ ] ลบจุดเก็บที่มีของอยู่ไม่ได้ และขึ้นข้อความบอกว่ายังมีของค้างอยู่กี่ชิ้น
  - [ ] ลบจุดเก็บที่ว่างอยู่ได้ตามปกติ

### US-005 · เตือนของใกล้หมดอายุ
- **ในฐานะ:** คนในบ้าน · **ฉันต้องการ:** รู้ว่าของอะไรต้องใช้ก่อน · **เพื่อที่จะ:** ใช้ของทันเวลาและลดของเสีย
- **ที่มา:** ข้อ 2, 8, 9
- **เกณฑ์การตรวจรับ:**
  - [ ] ของที่เหลืออายุ ≤ 3 วัน แสดงสถานะ "ใกล้หมดอายุ" (เหลือง) พร้อมจำนวนวันที่เหลือ
  - [ ] ของที่เลยวันหมดอายุแล้วแสดงสถานะ "หมดอายุ" (แดง)
  - [ ] ของที่ไม่ได้กรอกวันหมดอายุ ไม่ถูกนับว่าใกล้หมดอายุ
  - [ ] มีมุมรวบรวมของใกล้หมดอายุ/หมดอายุไว้ในที่เดียว
  - [ ] เปิดแอปแล้วมีสรุปสั้น ๆ ว่า "มีของต้องใช้กี่รายการ"
  - [ ] เดโมเปิดมาแล้วเห็นสถานะนี้ทันทีโดยไม่ต้องแก้ข้อมูล (มีของใน seed ให้ครบทั้งเหลืองและแดง)

### US-007 · ใช้หมดแล้ว / ประวัติย้อนหลัง
- **ในฐานะ:** คนในบ้าน · **ฉันต้องการ:** ดูย้อนหลังว่าอะไรใช้หมดไปแล้ว · **เพื่อที่จะ:** รู้ว่าอะไรซื้อบ่อยและนำกลับเข้าบ้านเมื่อซื้อมาอีก
- **ที่มา:** ข้อ 10
- **เกณฑ์การตรวจรับ:**
  - [ ] เข้าถึงมุม "ใช้หมดแล้ว" ได้จากเมนูหลัก
  - [ ] เห็นชื่อของที่ใช้หมดและวันที่ที่กดใช้หมด
  - [ ] กด "นำกลับเข้ารายการ" แล้วของกลับไปอยู่ในหน้ารายการพร้อมจำนวนที่ตั้งใหม่ได้
  - [ ] ของที่อยู่ใน "ใช้หมดแล้ว" ไม่ปนกับรายการของที่ยังมีอยู่

### US-008 · รายการที่ต้องซื้อ
- **ในฐานะ:** คนในบ้าน · **ฉันต้องการ:** จดไว้ว่าต้องซื้ออะไร · **เพื่อที่จะ:** ไม่ลืมของที่ต้องซื้อ
- **ที่มา:** ข้อ 12, 16 (เลือกแบบสมุดโน้ตอิสระ)
- **เกณฑ์การตรวจรับ:**
  - [ ] พิมพ์เพิ่มรายการที่ต้องซื้อเองได้
  - [ ] ติ๊ก "ซื้อแล้ว" แล้วรายการนั้นหายออกจากรายการที่ต้องซื้อ
  - [ ] ลบรายการที่ยังไม่ซื้อออกได้
  - [ ] รายการที่ต้องซื้อคงอยู่หลังรีเฟรช (เก็บใน localStorage)
  - [ ] ไม่ผูกกับรายการของ — ไม่มีการเพิ่มหรือลบของในสต็อกอัตโนมัติ
  - [ ] แต่ละรายการเป็นข้อความช่องเดียว ไม่มีช่องจำนวน หมวดหมู่ หรือจุดเก็บ (ยืนยันตาม OQ-13)

### US-009 · ย้ายของระหว่างจุดเก็บ — 🆕 เพิ่ม 2026-10-16 (รอการรับรองถ้อยคำ)
- **ในฐานะ:** คนในบ้าน · **ฉันต้องการ:** ย้ายของจากจุดเก็บหนึ่งไปยังอีกจุดเก็บหนึ่ง · **เพื่อที่จะ:** จัดบ้านใหม่ได้โดยไม่ต้องทิ้งของแล้วเพิ่มใหม่
- **ที่มา:** **คำถาม OQ-R16 ของ R001 (2026-10-16)** — ไม่มีในฉบับ v2.1 · เป็นช่องว่างที่เจ้าของโปรเจกต์พบตอนตรวจแบบร่าง: ข้อความ US-004 สั่งให้ "ย้ายของออกก่อนจึงจะลบได้" แต่ระบบไม่มีทางย้าย ⇒ ปุ่มลบที่เก็บเป็นทางตัน
- **Release ที่จะทำ:** **R005** (พร้อม US-003 ปรับจำนวน · US-007 ใช้หมดแล้ว) — สัญญาชั้นข้อมูลที่จะเพิ่ม: `moveLot(lotId, locationId)`
- **เกณฑ์การตรวจรับ:**
  - [ ] เลือกจุดเก็บปลายทางจากรายการจุดเก็บที่มีอยู่จริงได้
  - [ ] ย้าย **ทั้งล็อต** — ยอดของไม่เปลี่ยน (ยังไม่ต้องรองรับการย้ายบางส่วน)
  - [ ] สินค้าที่มีหลายล็อตย้ายทีละล็อตได้
  - [ ] ย้ายของออกจนจุดเก็บว่าง แล้วลบจุดเก็บนั้นได้ → ปลดทางตันของ US-004
  - [ ] ลบจุดเก็บที่มีของอยู่ไม่ได้ และข้อความบนจอตรงกับการกระทำที่ทำได้จริง

## 4. ข้อกำหนดอื่น ๆ (Non-functional Requirements)

### 4.1 การแสดงผล (Responsive — บังคับทุกขนาด)
ต้องใช้งานได้ครบทั้งสามขนาด ไม่ใช่แค่ย่อขนาดลง

| ขนาด | ช่วงความกว้าง | เกณฑ์การตรวจรับ |
|---|---|---|
| มือถือ | 360–767 px | ทำภารกิจหลักครบ: ดูรายการ · เพิ่มของ · ปรับจำนวน · ดูมุมใกล้หมดอายุ · เพิ่มรายการต้องซื้อ |
| แท็บเล็ต | 768–1023 px | ใช้งานได้ครบ โดยใช้พื้นที่กว้างขึ้น (เช่น แสดงการ์ด 2 คอลัมน์) |
| เว็บ | ≥ 1024 px | ใช้งานได้ครบ ไม่ยืดเต็มจอจนอ่านยาก |

- [ ] ทดสอบที่ความกว้าง 375 px / 768 px / 1280 px แล้วทำภารกิจหลักได้ครบทั้งสามขนาด
- [ ] ไม่มีแถบเลื่อนแนวนอนในทุกขนาด
- [ ] ปุ่มและช่องกรอกบนมือถือกดได้สะดวก (ไม่เล็กจนกดพลาด)

### 4.2 ภาษาและความเข้าใจ
- [ ] ข้อความทั้งหมดเป็นภาษาไทย ใช้คำที่คนในบ้านเข้าใจทันที
- [ ] สถานะของใช้สีและข้อความกำกับคู่กัน (ไม่สื่อด้วยสีอย่างเดียว)

### 4.3 ความเร็ว
- [ ] บันทึกของเสร็จได้ในไม่กี่ขั้นตอน เหมาะกับการทำตอนของเข้าบ้านจริง
- [ ] เปิดแอปแล้วเห็นรายการภายใน **1 วินาที** บนเครื่องทั่วไป (ข้อมูลอยู่ใน localStorage จึงไม่มีเวลารอเครือข่าย — เกณฑ์ยืนยันแล้วตาม OQ-14)

### 4.4 ข้อมูลและความเป็นส่วนตัว
- [ ] ข้อมูลทั้งหมดอยู่ใน localStorage ของเบราว์เซอร์เครื่องนั้น
- [ ] ไม่มีข้อมูลใดถูกส่งออกไปนอกเครื่อง
- [ ] เปิดดูข้อมูลได้แม้ไม่มีอินเทอร์เน็ต (ข้อมูลอยู่ที่เครื่องอยู่แล้ว)
- [ ] เดโมเปิดมาแล้วมีข้อมูลตัวอย่างพร้อมใช้ ตามตารางข้อ 5.3
- [ ] มีปุ่ม "รีเซ็ตข้อมูลตัวอย่าง" ที่กดแล้วคืนค่า seed กลับมาได้ทุกเมื่อ (ตาม OQ-11)

### 4.5 การติดตั้งใช้งาน (PWA — ตาม OQ-12)
- [ ] มี manifest ที่ระบุชื่อแอป ไอคอน และสีธีม
- [ ] เพิ่มลงหน้าจอโฮมบนมือถือได้ และเปิดจากไอคอนแล้วทำงานเต็มหน้าจอ (ไม่มีแถบเบราว์เซอร์)
- [ ] ยังใช้งานบนเบราว์เซอร์ปกติได้ครบทุกความกว้างตามข้อ 4.1
