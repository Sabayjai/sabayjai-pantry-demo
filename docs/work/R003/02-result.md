## 1. สิ่งที่ส่งมอบ

**ฟอร์ม `#/add` จอจริง (S1 · US-001)** — เขียน `src/views/item-form.js` ใหม่ทั้งหมด:
- ช่องบังคับ ชื่อ · จำนวน (ค่าเริ่ม 1) · หน่วย (ค่าเริ่ม ชิ้น) · จุดเก็บ — ไม่ครบ + ข้อความใต้ช่อง + โฟกัสช่องแรก (พิสูจน์แล้ว: บันทึกเปล่า → `กรอกชื่อของ` + `เลือกจุดเก็บ` + โฟกัสช่องชื่อ)
- ช่องไม่บังคับ หมวดหมู่ · วันหมดอายุ (`type=date`) · หมายเหตุ (เกิน 200 มีข้อความบอกผ่าน validate เดิม)
- ช่วยกรอกของเดิม: พิมพ์ ≥ 2 ตัวอักษร → เสนอ ≤ 5 รายการ (เรียง ก-ฮ) → เลือกแล้วเติมหน่วย/หมวดหมู่/หมายเหตุให้ (พิสูจน์แล้ว: `นมสด` → `นมสด 1 ลิตร · กล่อง` → หน่วยเป็นกล่อง หมวดเป็นพร้อมกิน)
- หน่วยพิมพ์ใหม่ได้: ตัวเลือก `พิมพ์หน่วยใหม่…` → ช่องกรอก → เข้า `receiveStock` (พิสูจน์แล้ว: `กระสอบ` → ครั้งหน้าโผล่ใน dropdown)
- เพิ่มจุดเก็บ/หมวดหมู่ inline ในหน้านี้ (พิสูจน์แล้ว: เพิ่ม `ของแห้ง` → ถูกเลือกทันที → บันทึก `ถั่วเขียว` ได้ `3 ชิ้น · ชั้นวางของ · ของแห้ง`)
- dropdown จุดเก็บ/หมวดหมู่แสดงเฉพาะที่ใช้งาน (ของพักใช้ R002 ไม่โผล่) · บันทึกสำเร็จ → `#/items` + toast `เพิ่ม "…" แล้ว` (พิสูจน์แล้วทั้ง toast และยอดรวมแบทช์: นมสดกลายเป็น `2 กล่อง · ตู้เย็น · พร้อมกิน · 2 ล็อต`)

**องค์ประกอบเพิ่ม (Task 4):** `showToast()` ใน `src/ui/components.js` (`role=status` หายเอง 5 วิ) + CSS ฟอร์ม/toast ใน `src/styles/main.css` (`.form` · `.field` · `.field-row` 2 คอลัมน์ ≥768px · `.suggest` · `.toast`)
