## 1. สิ่งที่ส่งมอบ

**S1 · ปรับจำนวน + undo + ย้ายของ (US-003 + US-009)** — `src/views/items.js` (เขียนการ์ดใหม่):
- `qty-stepper` บนการ์ด: − = `consumeProduct(productId, 1)` หักแบบ FEFO · + = เติมเข้าล็อตล่าสุด 1 หน่วย (OQ-R5-1) · ติดลบไม่ได้ (db clamp)
- ปุ่ม `ใช้หมดแล้ว` ระดับการ์ด = ทุกล็อตของสินค้านั้น → 0 พร้อมกัน (OQ-R5-2)
- `toast-undo` 5 วิ ครั้งละ 1 อัน (อันใหม่มาแทนอันเก่า · OQ-R5-3): `src/data/undo.js` (`remember`/`undoLast`/`clearUndo` — จำภาพ state ก่อนเปลี่ยน กู้ได้ 1 ขั้น)
- ปุ่มย้ายทีละล็อต (OQ-R5-4 · OQ-R16): สินค้าล็อตเดียวปุ่ม `ย้ายไปจุดเก็บ…` บนการ์ด · หลายล็อตปุ่ม `ย้าย` ในแถวล็อต → ฟอร์ม inline (dropdown ปลายทางเฉพาะที่ใช้งาน ไม่รวมที่เดิม + ช่องจำนวนเริ่มเท่าทั้งล็อต) → `moveLot` (ทั้งล็อตไม่เขียน movement · บางส่วนแยก batch + movement `out`/`in` คู่)
- CSS: `.stepper` · `.undo-toast` · `.toast` · `.card-move` · `.move-form` ใน `src/styles/main.css`

**S2 · มุมใช้หมดแล้ว (US-007)** — `src/views/used-up.js` (เขียนใหม่จากโครง):
- แถวละ 1 ล็อตยอด 0: ชื่อสินค้า · `เคยมียอด N หน่วย · ใช้หมดเมื่อ YYYY-MM-DD` (ยอดเดิมจาก `usedUpQuantity` · วันที่จาก movement ล่าสุด) · ไม่ปนกับของที่มีอยู่
- ปุ่ม `นำกลับเข้ารายการ` → ฟอร์ม inline กรอกจำนวนใหม่ (เริ่มเท่ายอดเดิม) → `restoreLot` → กลับไปโผล่ `#/items` + toast · จุดเดิมโดนพักใช้บันทึกไม่ได้ โชว์ข้อความ db inline
