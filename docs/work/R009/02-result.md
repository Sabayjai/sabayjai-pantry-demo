## 3. ปรับระหว่างตรวจ (จอผู้ใช้ 360px)

- แถวกิจกรรม `ย้าย/ทิ้ง/หมด/ประวัติ` ตกบรรทัด (ประวัติหล่นบรรทัดสอง) → เบียด `.btn-activity` (padding 8px · ฟอนต์ 13px) + `gap` 6px → 4 ปุ่มบรรทัดเดียวครบที่ 360px ปุ่มยังสูง 44px · `npm test` 84/84 · build ผ่าน

## 4. ปรับระหว่างตรวจ (รอบ 2 · toast-undo)

- toast-undo ขึ้นเป็นก้อนกลมบังการ์ด (ข้อความไทยไม่มีช่องว่าง + toast ไม่มี width คงที่ → flex บีบแคบ) → เปลี่ยน `.toast`/`.undo-toast` เป็นแถบบาร์กว้าง `min(480px, 100vw-32px)` มุม 16px + `safe-area` + เงา · กด Esc ปิดได้ (หมดสิทธิ์ undo เหมือนปล่อยหมดเวลา) · กัน listener เก่าค้างตอนอันใหม่มาแทน · ตรวจที่ 360px: บาร์ 328×68 ข้อความครบ ปุ่มย้อนกลับแถวเดียวกันสูง 44px · `npm test` 84/84 · build ผ่าน

## 5. ปรับระหว่างตรวจ (รอบ 3 · โทนสี toast)
