## 1. เป้าหมายของ Release (Goal)

มุม `#/expiring` รวมของที่ต้องใช้ก่อนไว้ที่เดียว + เปิดแอปมีสรุปสั้น ๆ (ป้ายเหลือง/แดงบนการ์ดมีตั้งแต่ R001/R004 แล้ว รอบนี้ไม่แตะ)

## 2. ขอบเขต (Scope)

- **ทำ:** จอ `#/expiring` จริง (กลุ่มหมดอายุแล้ว → ใกล้หมดอายุ · เรียงวันน้อยก่อน · แถวละล็อต: ชื่อ · จำนวน · จุดเก็บ · ป้าย) · สรุปตอนเปิดแอป (toast ครั้งเดียวต่อ session เฉพาะเมื่อมีของต้องรีบใช้ + log หลักฐาน) · CSS `.expiring-group`
- **ไม่ทำ:** การแจ้งเตือนล่วงหน้าแบบ push/schedule (นอกสโคปเดโม localStorage) · แก้ไขวันหมดอายุจากมุมนี้ (แก้ที่ฟอร์มเพิ่มของ R003)
- **ของที่มีอยู่แล้ว:** `expiringLots` · `expiringSummary` (มี+เทสต์) · `statusBadge` · `summaryBar` · `showToast`
