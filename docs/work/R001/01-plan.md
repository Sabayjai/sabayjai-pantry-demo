## 1. เป้าหมายของ Release (Goal)

วางรากให้พร้อมต่อยอด โดยยังไม่ทำฟีเจอร์ครบ — จบ Release นี้แล้วต้องได้:
1. **เอกสารออกแบบ** ที่ `docs/design/` (สถาปัตยกรรม · Data Model · สัญญาระบบ)
2. **โครงโปรเจกต์ที่รันได้** + **ชั้นข้อมูล** (localStorage + seed + รีเซ็ต)
3. **โครงหน้าจอหลัก** ที่เปิดแล้วเห็นรายการ seed ได้

## 2. ขอบเขต (Scope)

- **ทำ (In Scope):** Sprint S1 และ S2 ข้างล่างทั้งหมด
- **ไม่ทำ (Out of Scope):** ฟีเจอร์ตาม US-001 … US-008 (ยกไป R002–R007) · การขัดเกลา Responsive/PWA เต็มรูปแบบ (R008) · งานอนาคตตาม OQ-15

## 3. Sprint & Task

### Sprint S1 · Design
> เป้าหมาย: ตกลงแบบก่อนเขียนโค้ด — ผลส่งมอบคือเอกสารออกแบบที่ `docs/design/`
- [ ] **Task 1 · ยืนยันสแต็ก** — Static HTML/CSS/JS + Vanilla JS (แนะนำ) หรือ Vite + เฟรมเวิร์ก
- [ ] **Task 2 · สถาปัตยกรรม** — รูปแบบแอป (หน้าเดียว/หลายหน้าจอ) · การนำทาง · การแบ่งโมดูล
- [ ] **Task 3 · Data Model** — Item · Location · Category · UsedUp · ShoppingItem ตามข้อ 5 ของ requirement
- [ ] **Task 4 · สัญญาระบบ** — รายชื่อฟังก์ชันชั้นข้อมูล (อ่าน/เพิ่ม/แก้/ลบ) + รูปแบบอินพุต/เอาต์พุต

### Sprint S2 · Foundation & Data layer
> เป้าหมาย: โครงที่รันได้ + ข้อมูล seed แสดงบนจอ
- [ ] **Task 1 · โครงโปรเจกต์** — โครงไฟล์ + หน้าจอ shell (เมนูหลัก/การนำทาง)
- [ ] **Task 2 · ชั้นข้อมูล localStorage** — อ่าน/เขียนครบทุก entity ตาม Data Model
- [ ] **Task 3 · Seed + รีเซ็ต** — ข้อมูลตัวอย่าง (มีสถานะเหลืองและแดง) + ปุ่ม "รีเซ็ตข้อมูลตัวอย่าง" (OQ-11)
- [ ] **Task 4 · เรนเดอร์ seed** — แสดงรายการของจาก seed บนหน้าจอ (ยังไม่มีฟอร์มเพิ่ม/ค้นหา)
- [ ] **Task 5 · เกณฑ์ความเร็ว** — ยืนยันเปิดแอปแล้วเห็นรายการภายใน 1 วินาที (OQ-14)

---

## 4. เกณฑ์การตรวจรับของ Release (Acceptance Criteria)

Release นี้ถือว่า "เสร็จ" เมื่อ:
- [ ] มีเอกสารออกแบบครบหัวข้อที่ `docs/design/` (S1)
- [ ] เปิดแอปในเครื่องแล้วเห็นรายการของจาก seed โดยไม่ต้องแก้ข้อมูล (S2)
- [ ] seed มีของครบทั้งสถานะ **เหลือง (ใกล้หมดอายุ)** และ **แดง (หมดอายุ)** (S2)
- [ ] ปุ่ม "รีเซ็ตข้อมูลตัวอย่าง" กดแล้วคืนค่า seed ได้จริง (S2)
- [ ] ข้อมูลคงอยู่หลังรีเฟรช อยู่ใน localStorage ของเครื่องเท่านั้น ไม่มี Backend (S2)
- [ ] เปิดแอปแล้วเห็นรายการภายใน **1 วินาที** (S2 · OQ-14)

## 5. ข้อสังเกต / คำถามที่ต้องตัดสินใจ (Open Questions)
