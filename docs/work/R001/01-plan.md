## 4. เกณฑ์การตรวจรับของ Release (Acceptance Criteria)

Release นี้ถือว่า "เสร็จ" เมื่อ:
- [ ] มีเอกสารออกแบบครบหัวข้อที่ `docs/design/` (S1)
- [ ] มีแบบร่าง UX/UI + prototype คลิกได้ครบ 8 เส้นทาง เจ้าของโปรเจกต์ตรวจรับแล้ว (S3)
- [ ] เปิดแอปในเครื่องแล้วเห็นรายการของจาก seed โดยไม่ต้องแก้ข้อมูล (S2 ลิสต์เรียบ → S3 การ์ดตามแบบ)
- [ ] seed มีของครบทั้งสถานะ **เหลือง (ใกล้หมดอายุ)** และ **แดง (หมดอายุ)** และแอปแสดงป้ายให้เห็นจริง (S2/S3)
- [ ] ปุ่ม "รีเซ็ตข้อมูลตัวอย่าง" กดแล้วคืนค่า seed ได้จริง (S2)
- [ ] ข้อมูลคงอยู่หลังรีเฟรช อยู่ใน localStorage ของเครื่องเท่านั้น ไม่มี Backend (S2)
- [ ] เปิดแอปแล้วเห็นรายการภายใน **1 วินาที** (S2 วัดครั้งแรก · S3 ยืนยันซ้ำหลังใส่แบบ) (OQ-14)
- [ ] แบบร่างไม่มี scroll แนวนอนที่ 375 / 768 / 1280 px (S3 · ข้อ 4.1)
