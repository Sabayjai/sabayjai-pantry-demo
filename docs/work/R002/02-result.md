- **E1 · เทสต์:** `npm test` — 4 ไฟล์ 78 ตัวผ่าน (เดิม 77 + ใหม่ 1 เรื่องพักใช้/รับของเข้าที่พักใช้ไม่ได้) · `npm run build` — 23 modules ผ่าน

- **E4 · ไม่พังของเดิม:** console ไม่มี error · network ไม่มี request ล้มเหลว · `#/items` 8 การ์ดเหมือน R001 · ข้อมูลคงอยู่หลังรีเฟรช (localStorage)
- **E5 · บั๊กที่เจอระหว่างตรวจและแก้แล้ว:** (1) กดปุ่มเพิ่ม/กรอง/แก้ชื่อแล้วจอไม่ขยับ — view เก็บ state ระดับโมดูลแต่ไม่สั่ง re-render → เติม `notify()` หลังเปลี่ยน UI state · (2) บันทึกสำเร็จแล้วฟอร์มค้าง/ข้อความหาย — commit แจ้ง render ก่อนตั้ง flag → จัดลำดับ db-first แล้ว `notify()` ซ้ำหลังตั้งข้อความ · (3) ชื่อซ้ำแล้วฟอร์มปิดเงียบไม่ขึ้น error — ตั้ง flag ก่อนเรียก db ทำให้ catch มาไม่ทัน → ย้ายไป db-first เช่นกัน (ดู diff ใน `src/views/locations.js` · `src/views/categories.js`)
