## 1. สิ่งที่ส่งมอบ

- **S1 · Responsive — ไม่ต้องแก้โค้ด (ของเดิมผ่านทั้ง 3 ขนาด):** เทสเบราว์เซอร์จริงครบ 8 เส้นทางที่ 375 px (overflow = 0 ทุกจอ) · 768 px (การ์ด 2 คอลัมน์ `353.5px 353.5px` · เมนูแถวบน · ☰ ซ่อน) · 1280 px (เมนูซ้าย 240px · เนื้อหากว้างสุด 960 กลางจอ · overflow = 0) · ปุ่ม/ช่องกรอกที่เห็นทั้งหมดสูง ≥44px (มีแค่ลิงก์เมนูตอนพับที่สูง 0 เพราะซ่อนอยู่)
- **S2 · ภาษา & สถานะสี — ไม่ต้องแก้โค้ด:** กวาดข้อความที่ผู้ใช้เห็นเป็นไทยทั้งหมด (เหลือแค่ศัพท์เทคนิค `localStorage`/`Backend` ในจอตั้งค่า ซึ่งเป็นชื่อเฉพาะ) · ป้ายหมดอายุมีข้อความวันที่คู่สีเสมอ (`หมดอายุแล้ว · เลย 1 วัน` / `ใกล้หมดอายุ · เหลือ 2 วัน`) · ป้ายใช้งาน/พักใช้มีข้อความคู่สี · ช่องวันหมดอายุแสดงตามภาษาเบราว์เซอร์ (`<html lang="th">` ใส่ไว้แล้ว)
- **S3 · PWA & ออฟไลน์ (ของใหม่ 6 ไฟล์ + แก้ 2 ไฟล์):**
  - `public/manifest.webmanifest` — ชื่อ/ชื่อย่อ/คำอธิบายไทย · `start_url`+`scope` แบบ relative (`./` วางใต้ subpath ได้) · `display: standalone` · สีธีม `#1f7a5a` · ไอคอน 192/512 (`any`) + 512 (`maskable`)
  - `public/icons/` — `icon.svg` (โถขาวพื้นเขียว วาดมือ) + PNG ปั่นจากสคริปต์ครั้งเดียวแล้วลบสคริปต์ทิ้ง: `icon-192.png` · `icon-512.png` · `icon-maskable-512.png` (เว้น safe zone 66%) · `apple-touch-icon.png` 180 (ตรวจ IHDR แล้ว: ขนาด/8-bit/truecolor ถูกต้อง เปิดในเบราว์เซอร์เห็นรูปจริง)
  - `public/sw.js` — แคช app shell: ติดตั้งเก็บไฟล์หลัก 6 ไฟล์ · หน้าเว็บ network-first ตกแคชใช้ `index.html` (hash routing ใช้หน้าเดียวได้ทุกเส้นทาง) · asset cache-first (ชื่อไฟล์มี hash อยู่แล้วไม่กลัวค้าง) · แตะแค่ GET ใน origin ตัวเอง
  - `index.html` — ต่อ manifest + `theme-color` + `apple-touch-icon` + meta mobile-web-app (path แบบ `./` ตาม `base` เดิม)
  - `src/main.js` — ลงทะเบียน SW เฉพาะบิลด์จริง (`import.meta.env.PROD` + http(s) เท่านั้น · dev/file:// ข้ามเงียบ ๆ ไม่พังแอป)

- **activity set + ประวัติ + ปุ่มทิ้ง (ตามคำขอ — รื้อการ์ดทุกที่พร้อมกัน):** `discardLot` ระดับล็อตใน db (+เทสต์ movement `discard`) · `draftStepper`/`iconButton`/`historyTimeline` กลางใน `components.js` · การ์ด `#/items` เหลือ stepper ตัวเดียว + แถว `⇄ ย้าย` `🗑 ทิ้ง` `⛔ หมดแล้ว` `📜 ประวัติ` (ไอคอน+คำสั้น ซ่อนตามบริบท: ย้ายเฉพาะเมื่อมีจุดอื่น · บันทึกเฉพาะมีร่างค้าง) · แถว `#/expiring` ใช้ชุดเดียวกัน (เว้นย้าย/ประวัติ) · ประวัติกางใต้การ์ด (ใหม่สุดก่อน: วัน · รับเข้า/หยิบใช้/ทิ้ง/ปรับยอด/นำกลับ ±จำนวน · คงเหลือ) · มุม `#/used-up` มีป้าย `ทิ้ง` (แดง) / `ใช้หมด` (จาง) อ่านจาก movement ตัวสุดท้าย
- **ปุ่ม action pattern เดียวทุกจอ + ตัด `หมดแล้ว` เหลือ `หมด`:** กฎที่ใช้ทั้งแอป — งานหลัก `btn-primary` (บันทึก/เพิ่ม/ย้าย/นำกลับ) · งานรอง `btn-ghost` (ยกเลิก/ล้าง/แก้ชื่อ/ซื้อแล้ว/ลบ) · ยืนยันทำลาย `btn-danger` (มีใน confirm-dialog อยู่แล้ว) · กิจกรรมกะทัดรัด `btn-activity` ไอคอน+คำสั้น (การ์ด) · เก็บตกปุ่ม `btn` เปลือย 3 ตัวในจอตั้งค่า → `btn-ghost` · ปุ่มกิจกรรมเหลือ `⛔ หมด` (aria-label ยังเต็มว่าใช้หมดแล้ว) · ชื่อเมนู/หัวมุม/ประวัติยังใช้คำเต็ม `ใช้หมดแล้ว` เหมือนเดิม (เป็นชื่อมุม ไม่ใช่ปุ่ม action)
- **1 การ์ด = 1 ล็อต (ตามคำขอ):** เลิกจัดกลุ่มหลายล็อตในใบเดียว — `lotCard` ใบละล็อต (ชื่อ+ป้ายวันของล็อตนั้น · ยอด+จุดเก็บ+หมวด · stepper/ย้าย/ทิ้ง/หมด/ประวัติทีละล็อตตรง ๆ) · จอรายการกรอง/ค้นหาระดับล็อต (เกณฑ์เดียวกับ `filterStockRows` เดิม) เรียงแดง→เหลือง→ที่เหลือ · จอต้องใช้ก่อนแสดงเฉพาะล็อตที่ต้องใช้ แยกกลุ่มแดง/เหลือง · ตรวจแล้วที่ 375: การ์ด 8 ใบ · กรองตู้เย็นเหลือ 3 · ค้น `ยาย` เจอข้าวสาร · ร่าง+บันทึกระดับล็อต + undo
- **การ์ดภาษาเดียวกันทุกจอ + แก้ dropdown ฟอร์มย้าย:** `#/used-up` กับ `#/shopping` เลิกใช้แถว `item-row` เปลี่ยนเป็นการ์ด (`card-top` ชื่อ+ป้าย · `card-meta` · `card-actions`) · จุดเก็บ/หมวดหมู่ใช้ปุ่มไอคอนชุดเดียวกัน (`✏️ แก้ชื่อ` ghost · `⏸ พักใช้` danger / `▶️ เปิดใช้` primary · `iconButton` รองรับ variant danger แล้ว) · ปุ่มซื้อแล้วเป็น primary เต็ม (`✓ ซื้อแล้ว`) คู่ลบ ghost · dropdown ฟอร์มย้ายที่ดูแปลกเพราะป้ายเป็นวลีกริยา (`ย้าย "…" ไปจุดเก็บ`) ทับกับค่าที่เลือก — เปลี่ยนป้ายเป็นคำนาม `จุดเก็บปลายทาง` ตรง pattern dropdown ที่อื่น · เจออีกจุด: ลูกศรซ้อนสองอัน (native + วาดเอง) เพราะ `appearance: none` อยู่แค่ `.filter-row select` — ขยายคลุม `.inline-form select` เหลือลูกศรเดียว · ฟอร์มนำกลับในมุมใช้หมดแล้วอาการเดียวกัน (input เปลือย) — ห่อ `.field` + ป้าย `จำนวนที่นำกลับ (หน่วย)` แล้ว · ตรวจนำกลับเนยจืดกลับสต็อกได้ปกติ
- **ปุ่ม ✓/✕ ย้ายเข้าแถว stepper (ตามคำขอ):** จากแถวล่างขึ้นไปต่อหลังตัวเลขเป็น `− 3 + ✓ ✕` แถวเดียว (ไอคอนล้วนจัตุรัส 44px = pattern ปุ่มกิจกรรม · ความหมายอยู่ใน aria-label + โน้ต `จะเปลี่ยน 2 → 3` ใต้แถว) · ตรวจแล้วที่ 375: แถวเดียวไม่ล้น · กด ✓ บันทึกได้ปกติ
- **ตรวจแล้ว:** `npm test` 84 ผ่าน (ใหม่ 2) · `npm run build` ผ่าน · เบราว์เซอร์จริงที่ 375 — ลดโยเกิร์ต 4→2 แล้วบันทึก (ยอดเปลี่ยน + toast undo) · เพิ่มข้าวสารแล้วยกเลิก (กลับ 2) · `ใช้หมดแล้ว` น้ำปลาแล้วบันทึก (หลุดจากรายการ + toast undo) · มีแถวบันทึกโผล่ก็ overflow 0
