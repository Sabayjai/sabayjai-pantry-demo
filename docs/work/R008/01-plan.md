## 1. เป้าหมายของ Release (Goal)

ปิด NFR ให้ครบจนเดโมพร้อมส่ง R009 (Deploy): ใช้ได้ครบ 3 ขนาดจอ · ข้อความไทย + สีคู่ข้อความ · ติดตั้งลงโฮม + ออฟไลน์ได้

## 2. ขอบเขต (Scope)

- **ทำ:**
  - S1 · Responsive — เทส 375 / 768 / 1280 ทำภารกิจหลักครบ (ดูรายการ · เพิ่มของ · ปรับจำนวน · มุมใกล้หมดอายุ · เพิ่มรายการต้องซื้อ) · ไม่มี scroll แนวนอน · ปุ่ม/ช่องกรอกกดสะดวกบนมือถือ (≥44px)
  - S2 · ภาษา & สถานะสี — กวาดข้อความอังกฤษตกค้างในจอ → ไทย · สถานะทุกที่ใช้สี+ข้อความคู่กัน (ป้ายเหลือง/แดงมีข้อความวันที่ · ป้ายใช้งาน/พักใช้มีข้อความ)
  - S3 · PWA & ออฟไลน์ — `manifest.webmanifest` (ชื่อ/ไอคอน/สีธีม/display standalone) + ไอคอน 192/512 (+ apple-touch-icon) + meta theme-color + service worker (แคช app shell → เปิดซ้ำแบบออฟไลน์ได้) + ลงทะเบียนใน `main.js`
- **ไม่ทำ:** push/Notification API (Out of Scope) · สแกนบาร์โค้ด/รูป/เสียง (อนาคต) · เปลี่ยนโครงข้อมูลหรือเพิ่มฟีเจอร์ใหม่ · ติดตั้ง vite-plugin-pwa (ใช้ SW เขียนมือให้เบา ตรง stack Vanilla)
- **ของที่มีอยู่แล้ว (ไม่ต้องทำซ้ำ):** เมนู 3 ชั้น (☰ <768 · แถวบน ≥768 · ซ้าย ≥1024) · การ์ด 2 คอลัมน์ที่ ≥768 · `.wrap` max-width 960 · ป้าย `badge-warn/danger` มีข้อความ · ข้อมูล localStorage + seed 8 รายการ (เหลือง/แดงครบ) + ปุ่มรีเซ็ต (OQ-11) · log เรนเดอร์จอแรกเทียบเกณฑ์ 1 วิ (OQ-14)

## 3. Sprint & Task

### Sprint S1 · Responsive

- [x] **Task 1 · เทส 3 ขนาด + ซ่อมจุดแตก** — เปิด dev server ถ่ายจอ 375/768/1280 ครบ 7 จอ (items/add/locations/categories/expiring/used-up/shopping/settings) · เช็กไม่มี scroll แนวนอน · ซ่อมเฉพาะจุดที่แตก (ห้ามรื้อ layout)
- [x] **Task 2 · ปุ่มกดสะดวก** — กวาดปุ่ม/ลิงก์/chip/stepper ใน CSS ว่าแตะได้ ≥44px บนมือถือ

### Sprint S2 · ภาษา & สถานะสี

- [x] **Task 1 · กวาดภาษา** — ข้อความที่ผู้ใช้เห็นเป็นไทยทั้งหมด (aria-label นับด้วย)
- [x] **Task 2 · สีคู่ข้อความ** — ป้ายหมดอายุ/ใช้งาน-พักใช้/สถานะว่าง มีข้อความกำกับเสมอ ไม่มีจุดที่สื่อด้วยสีอย่างเดียว

### Sprint S3 · PWA & ออฟไลน์

- [x] **Task 1 · manifest + ไอคอน** — `public/manifest.webmanifest` + ไอคอน PNG 192/512 (+ maskable) + SVG + apple-touch-icon 180 · ต่อ `<link rel="manifest">` + theme-color + apple meta ใน `index.html`
- [x] **Task 2 · service worker** — `public/sw.js` (runtime cache: หน้า/asset same-origin cache-first · navigation fallback ไป index.html) + ลงทะเบียนใน `main.js` แบบไม่พังเมื่อเปิดผ่าน `file://` หรือเบราว์เซอร์เก่า · `npm run build` แล้ว `dist/` มี manifest + sw + icons ครบ
- [x] **Task 3 · ตรวจรับ + ปิด Release** — `npm test` · `npm run build` · เทสออฟไลน์ (โหลดครั้งนึง → ตัดเน็ต → รีเฟรชยังใช้ได้) · เขียน `02-result.md`
