# Work Tracking (แบบบาง ๆ สบายใจ)

โฟลเดอร์นี้ใช้สำหรับบันทึกและติดตามงานที่กำลังลงมือทำ โดยเน้นความเรียบง่าย ไม่ซับซ้อน เหมาะสำหรับการทำงานทั่วไปร่วมกับ AI

---

## รูปแบบการทำงาน

คุณสามารถแบ่งรอบงานเป็น Release หรือ Sprint แบบง่าย ๆ ได้ตามต้องการ เช่น:

```text
docs/work/
├── R001/
│   ├── 01-plan.md     # วางแผนว่ารอบนี้จะทำอะไร
│   └── 02-result.md   # บันทึกสิ่งที่ทำเสร็จ พร้อมหลักฐานตรวจรับ
└── templates/
    ├── plan.md        # เทมเพลตสำหรับเริ่มวางแผน
    └── result.md      # เทมเพลตสำหรับสรุปผลงาน
```

---

## กฎง่าย ๆ ในการลงมือทำ

1. **Plan ก่อนทำ:** เขียนเป้าหมายและสิ่งที่จะตรวจรับสั้น ๆ ลงใน `01-plan.md`
2. **ทำทีละเรื่อง:** ให้ AI ทำงานตามขอบเขตที่ตกลงไว้ในแผน
3. **สรุปพร้อมหลักฐาน:** เมื่อทำเสร็จ ให้บันทึกผลลงใน `02-result.md` เพื่อให้คนตรวจรับงานได้ง่าย
